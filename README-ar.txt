إصلاح تجريبي لمشكلة خط المصحف في السراج

يحتوي الأرشيف على 3 نسخ من الملف نفسه: المصدر ونسخة www ونسخة Android. التعديل يعيد علامة اتجاه RTL (U+200F) قبل كل حرف، كما كان في أسلوب العرض القديم. هذا سبب محتمل وليس ضمانًا نهائيًا قبل الاختبار.

طريقة الاستخدام:
1) انسخ مجلد المشروع كاملًا احتياطيًا، واحتفظ بملف APK القديم.
2) فك ضغط هذا الأرشيف داخل مجلد المشروع مع استبدال الملفات الثلاثة فقط.
3) من مجلد المشروع شغّل npm run sync.
4) افتح Android Studio ونفّذ Build > Build APK(s).
5) اختبر آيات متعددة على الهاتف. إذا لم تُحل المشكلة، ارجع إلى النسخة الاحتياطية.

لا يغيّر هذا التعديل نص القرآن أو ملف الخط.
